# Booking API QA

Учебный API-проект для портфолио: **Java + JUnit + REST Assured**, контрактные и негативные проверки, авторизация, идемпотентность и конкурентное бронирование.

## Запуск

Нужны JDK 21+ и Node.js 24. Укажите JDK в JAVA_HOME и добавьте node в PATH.

```powershell
.\mvnw.cmd -B -ntp test
```

Maven Wrapper загрузит Maven и зависимости. JUnit сам запустит локальный HTTP-сервис на свободном порту и завершит его после тестов. SQLite работает в памяти; Docker и внешняя база не нужны.

Отдельный набор:
```powershell
.\mvnw.cmd -B -ntp "-Dtest=ConcurrencyTest" test
```

Отчёты: `target/surefire-reports`; диагностика сервера: `target/fixture-stderr.log`.

## Что показать работодателю

36 запусков тестов проверяют создание и отмену брони, схемы ответов, поля и даты, недоступность чужих данных, повторные запросы и конкуренцию. В одном из тестов восемь запросов одновременно пытаются занять один интервал: успешным должен быть ровно один.

Архитектура: JUnit → lifecycle extension → API client + immutable request/builder → HTTP-сервис → SQLite. У каждого сценария свои комнаты, конфигурация REST Assured не хранится в глобальных изменяемых полях.

## Границы

Это учебная система, а не промышленная платформа бронирования. Авторизация демонстрационная; база и токены живут в памяти. Тесты конкурентных HTTP-запросов не измеряют производительность и не доказывают корректность распределённого сервиса. CI подготовлен для JDK 21 и 25; статус CI устанавливается только реальным запуском на GitHub.
